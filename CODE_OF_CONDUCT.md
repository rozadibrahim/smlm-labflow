# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.

In short: be respectful and constructive. Harassment, discrimination, and personal
attacks are not tolerated. We welcome contributions and questions from researchers of all
backgrounds and experience levels.

Report unacceptable behaviour to the maintainer (Rozad Ibrahim, ESBS, University of
Strasbourg). Reports will be handled confidentially.

The full text is available at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
